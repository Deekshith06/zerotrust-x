# Limitations

The project is production-oriented, not certified production-ready.

Implemented locally: deterministic pipeline, provenance/quarantine, rules, explainable risk, grounded read-only investigation, local RBAC, graph provenance, industrial console, readiness, manifests, tests, and reproducible artifacts.

Simulated: OIDC-capable configuration contract, tenant context boundary, adapter extension points, local audit semantics, and optional LangGraph adapter.

Unverified/planned: external OIDC provider validation, JWKS rotation, tenant-aware durable storage, distributed rate limiting, external immutable audit retention, load/p95/p99 benchmarks, backup drills, dependency/image scanning in CI, real enterprise connectors, verified threat labels, and legal/privacy compliance claims.

The source dataset is synthetic. It does not establish malicious insider behavior or real-world detection accuracy.
